# 高价值即时提醒档案

群里冒出「值得当场知道」的消息时，我会立刻推一条 Telegram 提醒，同时在这里留一份文件。
**周报看趋势，这里看现场。**

## 什么算「高价值」

命中下面任何一类关键词，才会提醒并留档；否则那一轮完全静默、什么都不留：

| 类别 | 关键词举例 |
|---|---|
| 招生 | 招生、招聘、PhD、博后、postdoc、全奖、助理教授、课题组、opening |
| 截止 | DDL、截止、deadline、报名截止、申请截止 |
| 结果 | offer、录取、面试、waitlist、拒信、放榜 |
| 机会 | 暑研、暑校、summer school、VISP、visiting、fellowship、实习 |
| 签证 | 签证、面签、拒签、10043、212f/212g、美签、I-20、DS-2019 |

**链接也算消息来源**：消息里的小红书（xhslink 短链）、微信公众号、普通网页会先抓正文，
再按正文内容判断值不值得提醒；抓不到就静默跳过，不会打扰。

## 结构

```
alerts\
  INDEX.md                                   ← 总索引，一行一次，先看这里
  README.md                                  ← 本文件
  2026\11\2026-11-07 1411 · 高价值提醒.md     ← 每次提醒一个文件
```

**文件名规则**：`<覆盖起点 YYYY-MM-DD HHMM> · 高价值提醒.md`
覆盖起点 = 这一批消息里**最早那条的时间**，不是提醒发送的时间——这样博士可以直接回群里对照。
（文件里第 3 行会注明「由 HH:MM 这轮即时提醒整理」，两者不混。）

## 一份提醒长什么样

```
# 2026-11-07 14:11 ~ 15:24 · 招生、签证：10043、F1

- 3 条 / 2 人 · 覆盖 11-07 14:11 ~ 11-07 15:24
- 由 11-07 18:00 这轮即时提醒整理（文件名取覆盖起点，方便回群里对照）
- 【招生】11-07 得等一个10.26 之后 申phd/master的F1 通过的案例 —23-少数-常远航
- 【签证】11-07 这么看来你科的10043似乎比交严重 —23-xx

> 标准：招生/DDL > 流程通知 > 经验帖 > 求问 > 闲聊
---
📖 注释
¹ 暑研：暑假进实验室做短期科研，主要用于攒经历、换推荐信
```

- 标题：`覆盖起点 ~ 结束 · 重点`，重点由命中类别 + 关键词自动拼（规则见 `tools\qq_alert.py` 的 `title_hint`）
- 第 2 行：条数与人数统计；第 3 行：来源回合
- 要点行：`- 【类别】MM-DD 原文摘要 —发言人`
- **每条要点都带 `MM-DD`**，与周报一致
- 行话用课本式脚注 `¹²³` + 文末「📖 注释」；这批没词命中时写「（本批没有需要解释的术语）」，保持格式统一
- **不带噪音行**——这里只收命中项，寒暄表情不进档案

## 备注

- 空回合不留档（静默就是静默，不造流水账）
- 补历史：`python tools\qq_alert_backfill.py --last N`（从 cron 输出重建，幂等）
- 索引自动重建：每写一份新文件，`INDEX.md` 会按覆盖起点倒序重排
