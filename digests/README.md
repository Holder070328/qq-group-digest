# QQ 群摘要档案

## 节奏

- **周报**：每周一 08:00，覆盖上周 7 天，Telegram 推送 + 存一份文件。
- **即时提醒**：每 20 分钟扫一次，只有命中「招生 / 截止 / 全奖 / offer / 机会」才推，其余时间完全静默。
- **归档**：每月 1 日 03:00，把 90 天以前的原始消息压进 `..\archive\*.jsonl.gz`。

## 结构

```
digests\
  INDEX.md                                        ← 总索引，一行一期，先看这里
  2026\10\2026-10-19（周报）· NUS招博DDL1.15.md     ← 每周一个文件
..\archive\
  2026-07.jsonl.gz                                ← 90 天以上的原始消息
```

**文件名规则**：`日期（周报）· 本周重点`。日期用**本周周一**，保证按名字排序＝按时间排序；后面跟 8～16 字重点。

## 一份周报长什么样

不超过 14 行：

```
# 2026-10-19 ~ 10-25 · NUS 招博 DDL1.15、复旦 AI3 招人

- 180 条 / 42 人 · 高峰 16–18 点
- 【招生】10-20 NUS CDE 李在乐组招 2027 Fall 全奖博士，DDL 1.15
- 【截止】10-18 国合部资助 9 月提交仍待审核，班主任称当日截止
- 【经验】10-19 NUS 理学院强 com；ISEM/CDE 强 prof 靠老板提名
- 【文件】10-16 PhD_Postdoc_Openings_Baier_lab.pdf；10-18 atomisticintelligence.github.io
- 噪音：表情/闲聊 40 条，重复转发已合并 6 条

> 标准：招生/DDL > 流程通知 > 经验帖 > 求问 > 闲聊
```

**每条要点都要带日期**（`MM-DD`，取消息原始时间，不是周报发布日）。周期越长，日期越重要——否则分不清哪条是新的。

## 怎么查

```
python tools\qq_archive.py --list          # 列出所有期
python tools\qq_archive.py --grep 博士     # 全文搜
python tools\qq_archive.py --today         # 看今天
```

桌面快捷方式：`桌面\QQ群摘要档案.lnk`

## 管道健康

`..\heartbeat.json` 记录：收到多少事件、命中白名单多少条、最近一次事件时间。
周报里「管道心跳」那一行就来自这里——**没人说话的时候，它证明管道还活着**。
掉线超过 14 小时（且不在深夜），即时提醒任务会单独告警一次。

## 约定

- 只写要点，不复述原文；一条一行，超过 40 字就砍。
- 每周一个文件，不合并、不覆盖。
- 原始消息在 `..\messages.db`（保留 90 天），更早的在 `..\archive\`。
- 摘要只给本人看，不对外转发。
