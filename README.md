中国科学技术大学「USTC飞跃群2027」（群号 1035480173）的自动整理档案。

群里每天聊的东西很多——招生、DDL、暑研、签证、经验贴，一刷就滚没了。这个仓库把它们压成两类文件：

| 文件夹 | 里面是什么 | 从哪看起 |
|---|---|---|
| **`digests/`** | **周报**：每周一份，覆盖过去 7 天的群聊要点（招生、截止、经验、求问、文件），含统计与分类 | [`digests/INDEX.md`](digests/INDEX.md) |
| **`alerts/`** | **高价值即时提醒**：招生 / 截止 / offer / 暑研 / 签证，命中才留一份，空回合不留档 | [`alerts/INDEX.md`](alerts/INDEX.md) |

两个文件夹都是 `年/月/<日期> · 内容.md` 的结构，各自的 `README.md` 里写了命名规则和样例。

即时提醒（命中才有一份）：


- 行话用课本式角标 `¹²³` 标注，文末「📖 注释」逐条用大白话解释

## 保存到本地，并跟着更新

### 第一步：拿一份下来（只需一次）

装了 [git](https://git-scm.com/downloads) 的话：

```bash
git clone https://github.com/Holder070328/qq-group-digest.git
```

没装 git 也可以：在 GitHub 页面点 **Code → Download ZIP**，解压即是一份完整档案。

### 第二步：以后每次更新（任选其一）

| 方式 | 怎么做 |
|---|---|
| **双击（最省事）** | Windows 双击仓库里的 `update.cmd`；mac / Linux 运行 `./update.sh` |
| 命令行 | 在仓库目录里 `git pull --ff-only` |
| GitHub Desktop | 打开仓库 → 点 **Fetch origin / Pull** |

`update.cmd` 里就是一句 `git pull --ff-only`，跑完会停住显示结果，不会一闪而过。

### 可选：每天自动同步（Windows）

任务计划程序里建一个每天运行的任务，操作填 `update.cmd` 的完整路径即可——开机后它会静默拉取最新档案。
